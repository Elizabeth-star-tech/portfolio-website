# Elizabeth Nangila - Portfolio Website

A modern, responsive personal portfolio website with a black and gold theme, built to showcase my skills, projects, education and experience.

Built as part of the Web Development Internship (Project Phase 2) at Sqrock IT Solutions.

## Live Demo

https://elizabeth-star-tech.github.io/portfolio-website/

## Sections

- **Home:** introduction, short bio and call-to-action buttons
- **About:** personal profile, career goals, education, interests and strengths
- **Skills:** animated progress bars for technical skills and cards for professional skills
- **Projects:** project cards with screenshots, descriptions, technologies, and GitHub and live demo links
- **Education and Experience:** a timeline of my studies, internship and community involvement
- **Resume:** buttons to view the resume in the browser or download it as a PDF
- **Contact:** contact details, social links and a validated contact form

## Features

- Fully responsive layout for mobile, tablet and desktop
- Sticky navigation bar with a hamburger menu on small screens
- Smooth scrolling between sections
- Skill bars that animate when they scroll into view
- Project cards rendered from a JavaScript data list
- Contact form with validation and clear error messages
- Hover effects and transitions throughout

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, CSS variables, media queries)
- JavaScript (ES6, Intersection Observer)

## How to Run Locally

1. Clone the repository:
   `git clone https://github.com/Elizabeth-star-tech/portfolio-website.git`
2. Open the folder in VS Code.
3. Open `index.html` with the Live Server extension, or open it directly in your browser.

No installation or build step is needed.

## What I Learned

- Building a single-page layout with smooth-scrolling navigation
- Designing a consistent dark theme using CSS variables
- Creating responsive layouts with CSS Grid, Flexbox and media queries
